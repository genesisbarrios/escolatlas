# AGENTS.md — Escolatlas

Next.js 16 (App Router) + React 19 + TypeScript + Tailwind 4. Single app: UI,
API routes, and data all live here. The previous Archie/Vite app is preserved
in `legacy/` — do not edit it; it is reference only and not part of the build.

## Commands

```bash
nvm use 22           # Node ≥ 22.18 — required (tests rely on TS type-stripping)
npm install
npm run dev          # http://localhost:3000
npm run build        # next build
npm start            # production server
npm test             # node --test tests/*.test.ts
npm run ingest       # re-fetch county GIS data → data/schools.json
```

Bun is not used. `npx tsc --noEmit` for a fast type-check.

## Layout

- `app/` — App Router pages + API routes (`app/api/schools`, `…/schools/[id]`, `…/match`).
- `lib/` — pure domain logic: `school.ts` (model), `filters.ts`, `rank.ts`,
  `nlp.ts` (heuristic parser), `data.ts` (JSON loader), `query.ts`, `geo.ts`,
  `compare-store.ts`. Pure modules must keep `.ts` extensions on relative
  imports (tests run them directly under Node's type stripping).
- `components/` — React components; map bits are client-only
  (`SchoolMap.tsx` via `MapClient.tsx` dynamic wrapper).
- `data/schools.json` — generated by `npm run ingest`; don't hand-edit,
  but do commit it.
- `tests/` — `node:test` suites, plain Node, no extra runner.

## Rules

- Never invent school data. Missing source fields stay `null` and render as
  "Not reported." `programs` may only be derived from a school's name.
- Explanations (`lib/rank.ts` reasons) must come from real attributes.
- Keep `lib/` free of React and `next/*` imports — it is exercised directly by
  Node tests.
- Environment: no secrets required; don't add provider keys without a code
  path that validates their output to `SchoolFilters`.
