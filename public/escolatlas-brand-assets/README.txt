EscolAtlas brand assets
=======================

Colors
  Atlas Blue  #3B8BD9  primary: logo, buttons, headlines
  Deep Atlas  #1F5A96  links and small blue text on light backgrounds
  Marigold    #F4B23C  accent: the book, highlights (never text on white)
  Ink         #14263D  body text, dark backgrounds
  Paper       #F4F8FC  page backgrounds

Fonts (free, Google Fonts)
  Bricolage Grotesque  wordmark + headlines ("escol" ExtraBold 800, "atlas" Regular 400)
  DM Sans              body and UI text

Which logo to use
  -color    on white / Paper / light photos
  -white    on Atlas Blue or busy photos
  -on-dark  on Ink / dark mode
  -black    one-color printing, stamps, embroidery

Text in the SVG logos is converted to outlines, so no font install is needed.
